# Security Policy

## Reporting a vulnerability

This project is a GitHub CLI extension. If you believe you have found a security
vulnerability in it, please report it privately rather than opening a public
issue.

- Email the maintainer at the address listed in the repository owner's profile.
- Include a description of the issue, the version affected, and a minimal
  reproduction if you have one.
- You can expect an acknowledgement within a few days.

Do not open a public issue, discussion, or pull request for a security report.

## Scope

- The `gh-debt` extension and its published npm package.
- The CI/CD pipeline in this repository.

Third-party dependencies are covered by Dependabot and code scanning; their
vulnerabilities are reported upstream rather than tracked here.

## Supported versions

Only the latest released version receives fixes. There is no long-term support
for older releases.
